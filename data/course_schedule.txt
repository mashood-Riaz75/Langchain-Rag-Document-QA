2. Course Descriptions
Python Programming introduces variables, data types, conditional statements, loops, functions, modules, file handling, and basic exception handling. The laboratory gives students practice writing and testing Python programs.

Database Fundamentals covers relational database concepts, tables, primary and foreign keys, SQL queries, joins, normalization, and transaction basics. The lab includes SQL exercises.

Web Development introduces HTML, CSS, JavaScript, HTTP concepts, frontend development, and basic backend integration. Practical sessions focus on building and testing small web pages and applications.

Data Structures covers arrays, linked lists, stacks, queues, trees, searching, sorting, and introductory algorithm analysis.

Academic Writing focuses on organizing paragraphs, writing clear arguments, citing sources, and revising technical documents.

4. Room and Schedule Notes
Room assignments may change if a laboratory or classroom is unavailable. Students should check the latest notice from the academic office before attending a session.

5. Consultation
Students may attend the Friday instructor consultation by appointment. They should send a request to the instructor and briefly describe the topic they want to discuss.

6. Student Support
The Wednesday student support hour is intended for questions about course registration, timetable conflicts, and finding academic resources. It is not a replacement for a formal appeal or assessment review.
